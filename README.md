# Shapes Project

This project contains code for creating and manipulating geometric shapes. It provides functionality to calculate the area of shapes. The code is designed to be modular and reusable for different shape-related operations.

## Features
- Support for two shapes: Circle and Rectangle.
- Methods to calculate area.
- Easy-to-extend structure for adding new shapes.

## Usage
Import the relevant classes and use the provided methods to perform calculations or manipulate shapes.

## Requirements
- Java Development Kit (JDK)
- Eclipse IDE (optional)

## How to Run
1. Clone the repository.
2. Open the project in your IDE.
3. Compile and run the desired classes.
